# 📚 Librefly – E-Book Management System

Welcome to **Librefly**, a modern and minimal e-book management platform. Designed for easy access and organization, Librefly lets **admins upload e-books** while allowing **registered users to explore, view, and download** them.

![Librefly Banner](https://via.placeholder.com/1000x250.png?text=Librefly+-+E-book+Management+System)

---

## 🔧 Tech Stack

- 💻 Frontend: **HTML**, **CSS**, **JavaScript**
- 🖥️ Backend: **PHP**
- 🗃️ Database: **MySQL**
- 🎨 UI Template: **AdminLTE**

---

## ✨ Features

- 🔐 **Admin Dashboard**  
  Upload, update, and manage e-books.

- 📖 **User Interface**  
  Browse books, view book details, and download in one click.

- 🧾 **Secure Login/Registration**  
  Role-based access for Admins and Users.

- 🔍 **Search & Filter**  
  Easily find books using search and category filters.
